# 주간묵상

주간묵상 HTML 자료를 지속적으로 게시하는 공개 저장소입니다.

- 고정 공유 주소: https://ai4pastor-dot.github.io/weekly-devotions/
- 배포 원본: `main` 브랜치의 `/docs`
- 배포 방식: GitHub Pages, push 후 자동 배포

## 매주 게시하기

1. 게시 주차에 해당하는 날짜를 확인합니다. 날짜는 사용자가 지정한 기준을 따릅니다.
2. `docs/YYYY-MM-DD/index.html`에 공개할 묵상 HTML을 저장합니다.
3. 필요한 이미지, CSS, JS만 해당 폴더에 함께 저장하고 상대 경로로 연결합니다.
4. `docs/index.html`의 이번 주 묵상 링크와 지난 묵상 목록을 갱신합니다. 기존 주차 링크는 보존합니다.
5. 변경한 파일만 검토하여 커밋하고 `main` 브랜치에 push합니다.
6. 해당 커밋의 Pages 배포 성공과 실제 페이지 내용을 확인한 뒤 링크를 공유합니다.

주차별 주소: `https://ai4pastor-dot.github.io/weekly-devotions/YYYY-MM-DD/`

매주 새 저장소를 만들지 않습니다. 같은 주차의 자료를 수정하면 기존 URL이 유지됩니다.
홈페이지 목록은 게시할 때 함께 갱신해야 하며, 문서 추가만으로 목록이 자동 생성되지는 않습니다.

## 공개 범위

저장소, 커밋 이력, 배포된 페이지는 모두 공개입니다. 개인정보, 비공개 기도제목, 상담 내용, API 키 등은 업로드하지 않습니다.
저작권이 있는 본문이나 이미지는 게시 권한을 확인합니다.
GitHub Pages는 정적 HTML 호스팅이며 비공개 로그인 보호나 서버 실행 기능은 제공하지 않습니다.
